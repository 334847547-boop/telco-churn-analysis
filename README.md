\# 电信客户流失分类



\## 项目问题



根据客户的账户、合同和服务特征，分析哪些特征与流失标签相关，并训练分类模型，估计样本客户的流失概率、进行风险排序。



\## 目标变量



`Churn`：`Yes` 表示客户已流失，`No` 表示客户未流失。按数据来源的定义，`Yes` 表示客户在最近一个月离开。



\## 预期用途



这是一个数据科学练习项目，用于练习数据分析、分类建模和模型评估。风险排序仅用于项目练习和进一步分析，不代表已经验证的客户挽留策略，也不能据此声称模型能减少实际流失。



\## 数据来源



\[IBM Telco Customer Churn 样本数据](https://github.com/IBM/telco-customer-churn-on-icp4d)



\## 评估计划



先建立简单基线，再比较分类模型。评估时关注流失类别的识别效果，例如召回率、精确率和 PR-AUC；再根据项目目标讨论分类阈值的选择。



\## 限制



该数据是样本数据，没有连续的客户时间记录，因此无法验证模型对未来客户或未来月份的预测能力。模型发现的特征与流失标签之间的关系也不代表因果关系，不能证明某种干预措施能够减少客户流失。
